# AXON — Build projects at thought speed

AXON is a high-performance project factory that turns your ideas into production-ready hackathon projects using advanced AI orchestration, deep market research, and real-time code synthesis.

## Features
- **Deep Research Engine**: Runs parallel searches to find unique wow factors.
- **Master Synthesis**: Generates full Next.js projects with design systems.
- **Live StackBlitz Preview**: Preview and edit your project in-browser.
- **Iterative Refinement**: Refine your project with natural language.

## Getting Started
1. Clone the repo
2. Install dependencies: `npm install`
3. Set up `.env.local` with your `GEMINI_API_KEY`
4. Run development server: `npm run dev`
